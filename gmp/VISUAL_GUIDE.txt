### 🔐 AUTHENTICATION FLOW

USER ACTION                    BACKEND API
─────────────────────────────────────────────
1. Enter phone                  
   Click "Send OTP" ────────→ POST /auth/send-otp
                             { phoneNumber, countryCode }
                              
2. Receive SMS ←──────────── { success, message, expiresIn }
   Enter 6-digit OTP
                              
3. Click "Verify" ──────────→ POST /auth/verify-otp
                             { phoneNumber, countryCode, otp }
                              
4. Success ←────────────────  { tempToken, isNewUser, user }
                              
   IF isNewUser = true:
   └─→ Navigate to Registration
       └─→ POST /auth/register-mobile
   
   IF isNewUser = false:
   └─→ Navigate to Home Screen
